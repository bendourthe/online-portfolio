# Manual Upload

## Upload Package

Run `node scripts/build-site.mjs` from the repository root in Windows PowerShell. A successful build reports that all local references resolved. Upload the contents of `dist/` into `/benjamindourthe.com/htdocs/`, preserving the relative paths. Do not upload the `dist` folder itself or the repository root.

The build adds content-based version queries to local CSS and JavaScript links in `index.html` and `skills.html`. Upload the generated HTML together with the matching CSS and JavaScript. Uploading only HTML cannot correct an outdated stylesheet stored on the server.

## Hosted Files

| Path | Hosting requirement |
| --- | --- |
| `index.html`, `skills.html` | Required public pages |
| `robots.txt`, `sitemap.xml` | Keep for search engines |
| `content/` | Required photos, downloads, portfolio images, and skill media, including `content/skills/assets/` |
| `css/`, `js/`, `favicon/` | Required styles, browser code, and site icons from the build |
| `nexus-hub/` | Required interactive Nexus Hub guide and training |
| Existing Google verification HTML | Keep the verification file already present on the host; it is not generated by this repository |

The top-level `assets/` folder contains only an unused copy of `Dourthe_Technologies_Headers.png`. Neither that image nor its identical repository-root copy has a reference in the tracked site or authoring files. Neither is needed online, and new builds exclude that folder. This does not apply to the required `content/skills/assets/` folder or assets inside the Nexus Hub guide. No hosted files were deleted during the audit.

## Nexus Verification

The canonical section address is `https://www.benjamindourthe.com/#nexus`. Existing `#featured-projects` bookmarks are converted to `#nexus` by the home-page script. After uploading, verify the two product buttons, normal feature-list wrapping, and the Studio logo. For a browser that still shows an older page, press `Ctrl+F5` once to reload its HTML and linked files.
